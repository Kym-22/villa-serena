Crea desde cero una aplicación web de escritorio para el MÓDULO DE LIMPIEZA de un Sistema de Gestión Hotelera para un hotel boutique llamado “Villa Serena”.

IMPORTANTE:
Esta aplicación es exclusivamente para el personal de LIMPIEZA del hotel. No crear módulos de reservas, pagos, huéspedes, cocina, restaurante, ventas, recepción ni administración.

Quiero un prototipo funcional con navegación entre pantallas y botones interactivos.

IDIOMA:
Toda la interfaz visible debe estar completamente en español. No utilizar palabras como Dashboard, Housekeeping, Checklist, Check-in o Check-out.

━━━━━━━━━━━━━━━━━━━━
ESTILO VISUAL
━━━━━━━━━━━━━━━━━━━━

Diseñar una interfaz elegante, seria, moderna y visualmente atractiva, inspirada en aplicaciones premium de hoteles boutique.

No quiero un dashboard empresarial genérico.
No quiero una interfaz formada únicamente por tablas y rectángulos blancos.
No quiero un diseño infantil ni excesivamente colorido.

La aplicación debe sentirse como un producto digital premium desarrollado específicamente para un hotel boutique.

No utilizar gradientes llamativos ni colores neón.

TIPOGRAFÍA:
Combinar una tipografía serif elegante para “Villa Serena”, números importantes y algunos títulos, con una sans serif moderna y legible para botones, estados, formularios y contenido.

Usar iconografía elegante, consistente y fácil de comprender.

FUNCIONES OBLIGATORIAS
━━━━━━━━━━━━━━━━━━━━

La aplicación debe representar estas funciones:

* Consultar habitaciones pendientes de limpieza.
* Actualizar el estado de limpieza.
* Registrar una limpieza finalizada.
* Consultar solicitudes de limpieza realizadas por huéspedes.
* Consultar solicitudes de artículos para habitaciones.
* Actualizar el estado de las solicitudes.
* Confirmar entrega de artículos.
* Reportar daños o desperfectos.
* Registrar objetos olvidados.
* Consultar habitaciones prioritarias.
* Consultar el detalle operativo de una habitación.
* Registrar observaciones de limpieza.
* Consultar el historial de servicios.

Hacer funcional la navegación.

Los botones deben producir cambios visibles en el prototipo.

Ejemplos:

“Comenzar limpieza” cambia la habitación a “En limpieza”.

“Finalizar limpieza” cambia la habitación a “Limpia”.

“Atender” cambia una solicitud de “Pendiente” a “En proceso”.

“Confirmar entrega” cambia una solicitud a “Atendida”.

“Registrar incidencia” agrega visualmente la incidencia.

RESULTADO ESPERADO
━━━━━━━━━━━━━━━━━━━━

El resultado debe parecer un software real de limpieza para un hotel boutique.

Debe ser visual, organizado y fácil de usar durante un turno de trabajo.

Tomar como inspiración visual los sistemas PMS hoteleros que utilizan mapas de habitaciones mediante tarjetas y estados fácilmente identificables, pero crear una identidad propia para Villa Serena.

Evitar una apariencia genérica de dashboard corporativo.

Priorizar:
elegancia + claridad + operación rápida + identidad hotelera.
